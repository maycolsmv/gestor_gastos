# 💰 Gestor de Gastos

Aplicación web para gestionar gastos e ingresos personales, desarrollada con Python y Streamlit.

> 🤖 Proyecto desarrollado con ayuda de IA (Claude - Anthropic)

## 🚀 Funcionalidades

- Registrar gastos e ingresos con categoría, método de pago y nota
- Resumen con balance total, gastos del día y del mes
- Gráficas interactivas (torta, barras, línea)
- Historial filtrable por tipo, categoría y fecha
- Buscador de movimientos
- Base de datos SQLite

## 🛠️ Tecnologías

- Python 3
- Streamlit
- SQLite
- Pandas
- Plotly

## ▶️ Cómo correr el proyecto

1. Instala las dependencias:
   pip install streamlit pandas plotly

2. Corre la app:
   python -m streamlit run app.py

3. Abre en el navegador: http://localhost:8501
